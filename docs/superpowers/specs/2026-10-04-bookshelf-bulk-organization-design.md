# Novel Tracker — 书架批量整理设计

日期：2026-10-04

## 目标与本轮边界

用户从旧记录导入几十本小说后，常要给多本书补相同的标签或作品类型。逐本打开详情、编辑、返回书架会重复很多次。本轮让用户在书架中选中明确的小说集合，一次性添加或移除标签，并可设置或清空作品类型。完成后，这些变化立即参与书架筛选和排序。

本轮只批量修改标签和作品类型。书名、作者、主角、封面、阅读状态、日期、评分、摘记及图片继续逐本编辑；不做批量删除、批量导出或自动根据书名推断标签。批量操作只修改本地书库，不需要账号或网络。

## 书架选书

- 书架提供“批量整理”入口。进入选择模式后，书卡出现清晰的勾选状态；轻点书卡切换选择，退出选择模式后恢复正常的详情导航。页面始终显示已选本数，以及“查看已选”“取消选择”和“继续整理”的入口。没有选书时不能继续。
- 现有关键词、阅读状态、作品类型、多个标签筛选和四种排序仍可使用。改变搜索、筛选或排序只改变当前显示的结果，不会悄悄取消之前选中的书；已选书以稳定书籍 ID 保存，而非列表位置。用户可在“查看已选”中核对并移除当前筛选下不可见的书。
- “全选当前结果”只选当下已完成查询、实际显示在结果列表中的书，不代表全书库，也不会自动选中之后因条件变化而出现的书。查询正在加载或失败时禁用全选并给出提示；无结果时不改变已有选择。已有选中项不会因新的筛选结果而自动增减。
- 主动取消整个批量整理流程或完成保存时清空本次选择；从预览返回书架调整条件和操作时保留选择。选择不写入数据库，也不随备份恢复；关闭 App 后不承诺恢复未提交草稿。选择模式下保留明确的取消入口，避免误以为轻点书卡仍会进入详情。

## 批量修改规则

- 操作区分三种意图：**添加标签**、**移除标签**、**作品类型**。标签分别从完整的系统及自定义标签库中多选，同一个标签不能同时列入添加与移除。添加只影响原本没有该标签的书；移除只影响原本带有该标签的书；其他标签保持不变，原有标签相对顺序保持不变，新增标签按用户选择的顺序追加。
- 用户可以在这次批量操作中创建自定义标签。名称沿用单书编辑的去首尾空白、非空和不与现有标签重名的规则；新标签只能用于本次“添加标签”，并且要与书籍变更一起成功或一起失败。不会自动把它设为快捷标签；系统预设标签不能在这里删除或改名。
- 作品类型有“保持各书原样”“设为耽美／言情／GL／无CP／其他”“清空作品类型”三种语义。默认保持原样；设置时用同一个类型替换每本选中书的旧类型，清空时写入无类型。界面不能把“未选择操作”误当成“清空”。
- 一次可以同时包含添加标签、移除标签和作品类型操作；必须至少选择一项操作。已经符合目标状态的书计为“无变化”，不重复写入。若预览中所有书均无变化，则提示无需保存并禁用最终确认。批量修改不得创建阅读历史、改变阅读次数、覆盖摘记、改动封面或影响未选中的书。

## 预览与确认

1. 用户在书架选择小说并设置操作后进入预览。预览显示选中书总数、实际会变化的书数、无变化的书数，以及每种操作影响的书数；同一本书可能同时计入多种操作，分项数量不相加。可查看每本书的书名、现有标签与作品类型、执行后的标签与作品类型；同名书须以作者或其他可用资料辅助辨认，并以内部 ID 保持准确归属。
2. 预览明确写出“添加”和“移除”分别作用于哪些标签，作品类型是保持、替换还是清空。用户可返回调整操作或选中集合；预览本身不写库。只有点最终“确认修改”才开始保存，取消及系统返回均不改变数据。
3. 保存时再次按所选书籍 ID 读取当前资料与标签，并核对预览时的修改时间、标签和作品类型。若有书被删除或在预览后被单书编辑、导入、恢复等流程改动，停止提交并要求重新生成预览，不能按过期预览覆盖新资料。
4. 所有选中书和本次新建的标签在一个数据库事务中提交。任一书或标签校验失败、写入失败时全部回滚，显示可重试错误；不能出现只整理了前半批的状态。保存期间禁用重复提交。成功后显示实际修改本数，清空选择并刷新书架；由于标签、类型和最近修改时间变化，书可能从当前筛选结果中消失或重新排序。

## 数据与兼容

- 批量整理使用现有 `books.type`、`book_tags` 和 `tags`，不新增书籍字段或数据库表。保存接口接收去重后的书籍 ID、标签添加／移除集合，以及明确的作品类型操作；页面不循环调用现有“编辑整本书”接口，因为那个接口还负责阅读状态和其他资料。
- 在事务中验证每本目标书及每个既有标签仍存在。仅对实际变化的书更新 `updated_at`；未变化的书保留原修改时间。标签关联的位置在修改后保持连续且顺序稳定。多个操作合并计算最终结果，再写入一次。
- 备份与开放格式导出继续使用当前的书籍、类型和标签数据结构，无须升级格式。旧书库、旧备份恢复后的书可同样参与批量整理；恢复后正在进行的未保存选择与预览作废。
- 快捷标签设置只控制新增页面展示，不限制这里可选的完整标签库。用户创建的标签进入全局标签库，可供以后单书编辑和批量整理使用，但不会自动加给未选中的书。

## 异常、性能与验收

- 空书架不能进入有目标的批量预览；选中书数为零、未指定有效操作、同一标签同时添加与移除、自定义标签重名或非法时，给出具体提示并保留用户已选内容。
- 搜索失败不能被当作零结果；查询未完成时不能对旧结果执行“全选当前结果”。选中较多书时仍显示真实数量，预览可滚动查看全部选中书，不只抽样；事务执行期间显示保存状态。
- 自动化测试覆盖：搜索／筛选／排序后选中书籍、跨筛选保留选择、全选当前结果、标签追加和移除、类型保持／替换／清空、同一批组合操作、无变化、重复自定义标签、过期预览与事务回滚，以及未选中书和阅读历史不变。
- iPhone 验收至少使用三本不同类型且标签有重叠的书：筛选后选两本、再切换筛选补选一本；确认“全选当前结果”不会选中隐藏书，检查预览前后差异；先取消，再提交，核对书架筛选、最近修改排序和详情中的标签／类型。模拟一次失败后确认没有半批修改。真机未测前不标为已通过。
