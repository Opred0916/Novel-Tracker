# Novel Tracker — 底部导航与视觉改版设计

日期：2026-10-04。最新需求同步：2026-10-05。状态：用户已确认补充调整，待更新开发计划并实施。

## 目标

让第一版书架更像一座可以长期使用的私人书库：小说优先出现，常用操作容易找到，选中状态有明确反馈，维护工具不会挤占首屏。修复 iPhone 顶部内容与系统状态栏重叠、状态栏和工具区拥挤、批量整理操作散乱、添加表单字段顺序不自然、选择控件样式不一致、管理页内容全部展开过长，以及默认封面排版生硬等问题。

本轮调整导航、布局、交互反馈、添加／编辑表单、默认封面和颜色呈现。现有小说、阅读历史、评分、摘记、图片、导入导出及备份数据保持原有含义。界面继续使用浅色方案，默认主题为墨绿。

## 信息架构：三个固定底部栏目

| 栏目 | 首页内容与入口 | 边界 |
| --- | --- | --- |
| 书架 | 小说列表、添加小说、阅读状态切换、搜索、排序、类型／标签筛选、随机想读、批量整理 | 浏览当前书库并对已经显示的书目发起操作。批量整理需要先选书，因此仍从书架开始。 |
| 回顾 | 书库概览、年度回顾、主题回顾卡片和年份选择 | 查看现有记录形成的统计与回顾，不放数据维护工具。 |
| 管理 | 标签与分类、旧记录导入、开放格式导出、备份与恢复、主题选择 | 维护书库数据和应用偏好，不重复展示回顾内容。 |

底部栏固定显示 `书架`、`回顾`、`管理` 三项。选中项使用主题主色，未选中项使用中性灰。小说详情、编辑、导入预览等子页面仍由上层导航承载并提供明确返回路径；返回按钮显示用户可理解的页面名，不能暴露 `(tabs)` 等路由组名称。

## 书架布局

### 顶部与阅读状态

- 页面使用 iPhone 安全区，标题、系统时间和刘海区域不得重叠。主标题缩短为“我的书架”，不再使用占据首屏的大幅宣传语；可省略副标题，让第一张书卡尽早出现。
- 阅读状态是书架的一级分区，包含“全部、想读、在读、读完、弃读”。五项保持单行横向滚动，以紧凑页签显示名称和数量，不因窄屏换行。
- 当前状态页签使用主题深色底、白字和可访问的选中状态；未选中项使用白底、中性边框。不能只改变文字颜色表示选中。
- 切换阅读状态不等同于叠加筛选。用户只切换到“想读／在读／读完／弃读”时，不显示“清除筛选”。相应空状态直接写“还没有想读的小说”等当前状态提示。

### 搜索、排序与筛选

- 状态页签下方放搜索框；搜索框提供清除当前关键词的独立 `×`。搜索范围仍为书名、作者、主角、摘记和已建立索引的图片文字。
- 搜索框下只常驻“排序”“筛选”和“更多”三个紧凑按钮。“批量整理”和“从想读中抽一本”收入“更多”菜单，减少首屏文字按钮堆叠。
- 排序和筛选点击后使用底部弹出面板。面板打开时对应按钮变为主题深色底与白字；排序选项显示当前项和勾选，选定后按钮继续显示当前排序，例如“最近修改”。
- 筛选面板包含单选作品类型和多选标签。生效后按钮显示条件数，例如“筛选 2”；这里的数量只计算作品类型和标签，不计算阅读状态、关键词和排序。
- “重置筛选”放在筛选面板内，仅清除作品类型和标签，保留当前阅读状态、搜索词和排序。搜索词由搜索框内的 `×` 清除，阅读状态由顶部页签切换。
- 页面没有额外类型／标签条件时，不显示常驻“清除筛选”文字；无结果提示根据实际条件提供“调整筛选”或清除搜索词的相应入口。

### 批量整理

- 从“更多”进入批量模式后，顶部工具区改为“取消、已选 N 本、全选当前结果”。书卡左侧显示选择控件，点击书卡切换选择。
- 页面底部显示固定的“整理所选”按钮；没有选择时置灰。点击后进入现有的标签／作品类型批量预览流程。
- 移除当前大块浅色面板和其中“全选当前结果、查看已选、继续整理、取消整理”四个并列文字入口。若需查看已选书，点击“已选 N 本”打开紧凑清单。
- 批量模式下隐藏“添加小说”主按钮，退出批量模式后恢复，避免两个底部主操作互相遮挡。

### 书卡与添加按钮

- 书卡稳定呈现封面、书名、作者和可选评分；阅读状态由顶部页签承担，不在卡片重复显示。评分使用紧凑的 `★ 5.0` 形式。
- 卡片减少多余高度和大面积主题色，确保书名和作者是主要信息。搜索命中摘记或图片文字时，仍保留现有命中摘要。
- “添加小说”是书架主按钮，固定在底部导航栏上方并避开安全区；列表底部预留相应空间，不能遮住最后一张书卡。

## 添加与编辑小说

### 字段顺序与条件显示

添加页从上到下为：阅读状态、书名、作者、首发平台、与状态相关的日期／评分／为什么想看、作品类型、快捷标签与全部标签入口、主角、封面、保存按钮。

- 阅读状态放在表单最上方，默认“想读”。书名仍是唯一必填字段，只填书名即可保存。
- 新增小说时，“为什么想看”仅在状态为“想读”时显示，始终选填；提示文字使用统一的可读灰色。用户暂时切换到其他状态时保留本次表单草稿，切回“想读”仍可继续编辑，但非“想读”状态保存时不新写入想看理由。编辑已有小说时，已经保存的理由仍可查看和修改，状态变化不能使旧资料失去入口。
- “在读、读完、弃读”继续按现有规则显示阅读日期；只有“读完”显示总体评分。状态切换不得清空用户已经输入但暂时隐藏的日期或评分草稿。
- 原“阅读平台”统一更名为“首发平台”，表示作品最初发表的平台。每本书第一版只保存一个可选的自由文本值，不要求从固定中文平台列表选择；内部字段暂时沿用 `platform`，避免无意义的数据迁移。

### 作者与首发平台建议

- 用户第一次保存作者或首发平台后，新增／编辑下一本书时可从已有记录中直接点选，也可继续输入新值。
- 建议值直接从书库内已有小说的非空作者和首发平台去重取得，不建立另一份历史表；删除或修改最后一本使用该值的书后，建议自然更新。
- 输入文字时只显示匹配的少量建议，完全匹配项不重复展示。建议属于快捷填写，不把字段变成必选，也不自动替用户选中。

### 作品类型与标签

- 阅读状态、作品类型和标签共用一致的选择规则：未选为白底与中性边框；选中为当前主题深色底、白字和勾选反馈。单选和多选的无障碍角色仍分别正确表达。
- 添加页只平铺用户设置的少量快捷标签，并提供“全部标签”入口。入口显示已选择的标签数量；点击后打开可搜索的标签选择面板。
- 全部标签面板支持多选、取消和新增自定义标签；关闭后保留选择。新增自定义标签不会自动加入快捷标签，快捷标签仍由管理页单独配置。
- 作品类型与快捷标签的尺寸、圆角和选中方式一致，不再出现阅读状态为深底白字、类型与标签却只变成绿字浅底的差异。

## 回顾与管理页面

回顾首页展示书库概览，并提供年度回顾和主题回顾卡片入口。统计口径和已有年份规则保持不变；空书库时可进入添加或导入。

管理页使用紧凑的分组列表，而不是把大按钮和所有设置直接铺开：

- “标签与分类”进入快捷标签和完整标签管理。
- “导入与整理”进入追加旧记录等数据整理入口。
- “导出与安全”进入开放格式导出、备份与恢复。
- “外观”只显示当前主题的色点、名称和进入箭头；点击后再展示八种主题预设。

每一行使用图标、名称、简短说明和箭头。危险的整体恢复仍使用原有确认流程。主题列表不在管理首页全部展开，避免占据多个屏幕高度。

## 主题与选择反馈

主题保留 8 个命名预设，每套定义主色、浅色底、按下色、背景、正文、边框、次要文字、评分和错误色。默认墨绿；页面背景为暖纸白，卡片为白色，正文为深灰黑，评分为暖金色，错误和删除为暗红色。

| 预设 | 主色 | 浅色底 |
| --- | --- | --- |
| 墨绿（默认） | `#28584E` | `#E8F1EC` |
| 雾蓝 | `#3E627D` | `#E9F0F5` |
| 陶棕 | `#865942` | `#F3EBE6` |
| 石榴红 | `#8B4352` | `#F6EAED` |
| 橄榄 | `#59633B` | `#F0F1E6` |
| 石墨 | `#445156` | `#ECEFF0` |
| 深海青 | `#27636C` | `#E6F2F2` |
| 琥珀 | `#805923` | `#F6F0E4` |

主题主色用于主要动作、已选状态、链接和底部栏；评分与错误继续使用独立语义色。按钮需要正常、按下、已选、禁用四种可辨状态；选中还应通过文字、勾选或无障碍状态表达，不能只靠颜色。

## 默认封面

没有自选封面的书继续使用本地绘制的书名封面，但重新调整小尺寸排版：减小内边距和圆角、使用更细的边框，根据封面尺寸选择字号和行高，避免三字书名被不必要地拆成三行。书名最多三行，过长时省略；移除粗短横线和英文品牌字样。

封面色仍由稳定书籍 ID 决定，使用低饱和纸张色。同一书重启后保持外观，切换界面主题不改变封面；真实封面图片保持原样。卡片正文始终显示完整书名，封面截断不影响辨认。

截图中的蓝色齿轮是 Expo Go 调试悬浮控件，不属于应用界面，正式页面不为它预留功能入口。

## 验收

1. iPhone 顶部内容与系统状态栏不重叠；书架首屏能看到状态页签、搜索、工具区和至少一张书卡。
2. 五个状态保持单行横向滚动。只切换状态时不出现“清除筛选”；类型或标签生效时筛选按钮变深、显示数量，排序面板明确勾选当前项。
3. 批量模式只有一套清楚的顶部选择栏和底部“整理所选”，不会与“添加小说”按钮重叠；取消后恢复普通书架。
4. 添加页首先选择阅读状态；非“想读”状态不显示“为什么想看”。作者和首发平台可以从已有记录选择，也能输入新值；只填书名仍可保存。
5. 阅读状态、作品类型和标签的选中样式一致；添加页只显示快捷标签，通过“全部标签”面板完成搜索、多选和新增。
6. 管理首页不直接铺开八种主题；标签、导入、导出／备份和外观均有紧凑清楚的入口。书库概览与年度回顾只在“回顾”栏目出现。
7. 默认封面在小书卡中保持书名可读，短书名不被过度拆行，长书名不溢出；真实封面和已有数据不受影响。
8. 自动化检查覆盖筛选清除边界、排序／筛选选中反馈、批量模式、条件字段、作者／首发平台建议、全部标签入口和默认封面；最终在 iPhone Expo Go 上检查安全区、窄屏、键盘、底部面板与返回文案。
