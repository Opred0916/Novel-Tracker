# Novel Tracker — 底部导航与视觉改版设计

日期：2026-10-04。状态：待用户审阅。

## 目标

让第一版书架更像一座长期使用的私人书库：找书和添加书直接、回顾阅读有独立位置，维护数据的工具易找但不挤占书架。改善状态筛选换行、入口堆叠、默认封面重复且排版生硬、紫色过重等问题。用户可以从多套协调的主题中选择自己喜欢的颜色，默认主题为墨绿。

这轮只调整导航、布局、默认封面和颜色呈现；现有记录、搜索、筛选、导入导出、备份与阅读规则保持原有含义。现阶段维持浅色界面；深色界面另行设计，不用简单反转当前颜色。

## 信息架构：三个固定底部栏目

| 栏目 | 首页内容与入口 | 边界 |
| --- | --- | --- |
| 书架 | 小说列表、添加小说、状态切换、搜索、作品类型／标签筛选、清除筛选、排序、批量整理 | 对当前书籍集合进行浏览或操作。批量整理从书架选择书目开始，因此留在书架。 |
| 回顾 | 书库概览、年度回顾与年份选择；从统计项进入相应小说／摘记 | 看过去记录形成的结果。这里不放修改书库数据的工具。 |
| 管理 | 快捷标签设置、追加旧记录、备份与恢复、开放格式导出、主题选择、使用与备份提示 | 维护书库数据和应用偏好。现有“数据管理”作为这一栏中的功能分组，避免重复入口。 |

底部栏始终显示三个图标与文字：`书架`、`回顾`、`管理`。选中项使用主题主色，未选中项使用中性灰。底部栏用于切换页面；新增、筛选、批量整理等动作仍在所属页面内。进入小说详情、编辑、导入预览等子页面后保留清楚的返回路径。切换栏目时保留当前书架搜索与筛选草稿，重新打开 App 时仍按既有规则初始化。

## 书架布局

从上到下依次为简短标题、状态栏、搜索框、筛选与排序入口、书卡列表。当前大幅宣传语缩小为轻量说明，优先把第一本书呈现在首屏。

- 状态栏为单行横向滚动的五项：全部、想读、在读、读完、弃读。状态名称和数量分层排版；不因屏幕宽度换成第二行。当前项用主题浅色底与主色文字表示，不能只靠颜色区别选中状态。
- 搜索框有清晰放大镜与可读的占位文字。排序和筛选是搜索框下的两个明确按钮；有效筛选存在时显示数量及“清除筛选”，无筛选时隐藏清除入口。
- “批量整理”放在书架工具区，进入后沿用现有选书与预览流程。快捷标签设置、数据管理、书库概览和备份与恢复从书架工具文字行移走。
- 添加小说使用书架页面的主要按钮，位置在底部导航栏上方，并为列表保留足够底部空间；不得遮住最后一张卡或底部栏。
- 书卡降低大面积主题色的使用。封面、书名、作者及评分形成稳定的阅读顺序；同名书仍可凭作者等资料辨认。

## 回顾与管理页面

回顾首页先展示现有的书库概览：各状态数量与真实完成记录统计；下面提供年度回顾入口和年份选择。年度回顾原有的数据口径不变，点书或摘记仍能回到原记录。空书库时提供添加或导入入口。

管理页按“分类偏好”“带入与带走记录”“外观”分组，分别容纳快捷标签、追加旧记录／备份恢复／开放格式导出、主题选择。数据管理不再作为另一层重复目录；旧页面可保留作内部路由，但用户只看到一条明确入口。整体恢复等有风险的操作仍使用原有确认流程。

## 主题系统

主题选择提供 8 个命名预设，每套至少定义主色、浅色选中底、按钮按下色；背景、正文、分隔线和语义色有统一规则。色板初稿：

| 预设 | 主色 | 浅色选中底 |
| --- | --- | --- |
| 墨绿（默认） | `#28584E` | `#E8F1EC` |
| 雾蓝 | `#3E627D` | `#E9F0F5` |
| 陶棕 | `#865942` | `#F3EBE6` |
| 石榴红 | `#8B4352` | `#F6EAED` |
| 橄榄 | `#59633B` | `#F0F1E6` |
| 石墨 | `#445156` | `#ECEFF0` |
| 深海青 | `#27636C` | `#E6F2F2` |
| 琥珀 | `#805923` | `#F6F0E4` |

页面底色统一为暖纸白 `#F6F3EC`，卡片为白色，正文为深灰黑 `#292D29`。评分维持独立的暖金色，错误和删除维持独立的暗红色；主题色用于主要动作、选中状态、链接和底部栏，不承担错误或评分含义。8 个主色上的白字对比度均超过 4.5:1；正式实现仍须在真实字号、浅色选中底与禁用态上检查对比度。

管理页展示 8 张小型主题预览卡，标出名称与选中状态。点击后立即预览并保存到当前设备；重启应用后保持选择。切换主题不修改小说资料、封面原图、备份内容或开放格式导出。现有散落在组件中的硬编码紫色需要收敛到统一主题令牌，避免出现半绿半紫的页面。用户尚未选主题时使用墨绿。

## 默认封面

没有自选封面的书使用本地绘制的书名封面：书名是主体，最多三行，过长时省略；去掉 `NOVEL TRACKER` 英文字样。以稳定书籍 ID 决定几套低饱和纸张色和简洁线条，使同一书重启后保持外观，不同书不会排成一片同色。封面色与用户选的界面主题独立，避免切换主题时书架中的所有封面一起变化。真实封面图片始终保持原样。最小书卡尺寸下仍能辨认书名；无法容纳的长书名由卡片正文完整显示。

截图中的蓝色齿轮未出现在当前书架组件中，初步判断为 Expo Go 调试悬浮控件；本设计不将其纳入应用导航。正式页面的管理入口由底部栏承担。

## 验收

1. iPhone 上三个底部栏目可稳定切换，子页面返回正确；书架搜索、筛选、排序和已选书目的现有行为不变。
2. 五个阅读状态在窄屏上一行横向滚动；搜索、筛选、清除筛选、批量整理及添加小说入口可见且不会遮挡列表。
3. 书库概览和年度回顾只从“回顾”入口进入；导入、备份、开放导出、快捷标签和主题从“管理”入口进入，无重复的书架工具文字堆。
4. 8 套主题均能即时切换、重启保持；页面、表单、日期操作、评分组件和底部栏没有残留紫色。选中与错误状态有文字或图形辅助，不仅依赖颜色。
5. 默认封面保留书名且清晰可读，同一书颜色稳定；用户封面图片和已有书籍数据不受影响。
6. 只运行与导航、主题和封面相关的自动化检查，最终在 iPhone Expo Go 上人工检查窄屏、键盘、底部安全区与返回路径。
