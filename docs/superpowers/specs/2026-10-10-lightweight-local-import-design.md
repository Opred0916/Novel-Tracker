# 轻量本地旧记录导入改版设计

## 目标与边界

面向整理书单文字、聊天/社交平台复制文字及截图 OCR 三类旧记录。目标是尽量提取有用信息，同时让用户快速核对不确定项，不静默写错书。全过程在本机完成；不调用云端智能识别、不下载大型离线模型、不引入付费能力。轻量规则不能理解任意自然语言，因此不承诺所有来源自动准确。

## 输入与数据流

现有文本输入、截图 OCR 与表格输入保留。文本和 OCR 输出统一进入“原文分段 → 线索提取 → 候选/待确认片段 → 预览修正 → 确认导入”流程。表格已有明确列映射，保留其解析方式，但复用整理预览。每个候选和片段必须保留来源行、原文；截图还保留原图引用。

分段器先识别换行、列表编号、常见分隔、书名号、字段标签及社交记录中的时间/昵称等边界。提取器只从明确线索或高可信组合生成书名、作者、评分、状态、摘记。无法明确归属的内容进入待处理原文；不得用相邻书目的字段填补缺失值。聊天昵称、日期、UI 文案可作为噪声提示，但必须允许用户查看原文。评分必须满足应用的 0.5～5、半星步进约束。

解析结果增加字段级证据/待确认状态，而不是只有整条候选与自由文本警告。原始文字不因用户修改字段而丢失。候选与片段使用稳定 ID，以便编辑、移动、合并及去重提示继续工作。导入提交仍走现有校验和重复确认流程，不直接绕过仓储约束。

## 整理预览

默认每条只显示书名、作者、评分、来源原文和明确的待确认标记；阅读状态、类型、标签、摘记等通过展开编辑。按来源顺序展示，便于与旧记录逐条比对。未归属文字集中显示，操作为“设为新书”“附为摘记”“忽略”；这些操作可以撤销或重新编辑。重复书目只提醒并要求选择，不自动合并。确认导入时阻止未处理片段及未确认的关键字段写入。

对大量记录，提供顶部计数和只看待确认项的入口，避免逐本穿过完整表单；仍可打开单条检查全部字段。键盘出现时输入框及确认操作保持可达。

## 错误与安全

OCR 错字、模糊作者/标题、跨行评分、日期与昵称混杂时，宁可给出待确认片段，也不制造确定值。空结果时展示原文并提供手动设为新书入口。文件过大、候选过多沿用现有限制并给出可理解提示。取消预览不写入书库；只有用户确认后才提交。

## 验收

- 整齐书单、作者在前/后的书名号记录、混杂聊天记录、截图 OCR 文本都进入同一预览，可见原文与来源。
- “水千丞 针锋对决 5分 / 水千丞 火焰戎装 5分”识别为两书，作者与评分不串行。
- “感想里提到作者或评分”不被强行拆成新字段；不确定内容可快速设书、附摘记或忽略。
- 无效评分、OCR 错字及重复书目不会无提示入库；用户可改正后导入。
- 文本、截图、表格原有提交与去重测试通过，并新增混杂样本、误识别和预览交互回归测试。

## 非目标

不做联网搜索、书名数据库匹配、云端大模型、离线大模型及自动纠正 OCR 错字。对没有清晰线索的散文式描述，系统只提供便捷整理，不声称能自动理解。
